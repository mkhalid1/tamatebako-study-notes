# 性格検査（OPQ）

玉手箱Ⅲの性格検査は、日本SHLの公式ページで「パーソナリティ（OPQ）」と書かれているものです。能力検査と違って正解はありません。このページでは、公式に説明されている仕組みと、受けるときの心構えをまとめます。

## OPQとは

日本SHLの[OPQの解説ページ](https://www.shl.co.jp/aboutus/keytechnologies/)によると、OPQ（Occupational Personality Questionnaires）は、1984年にSHLの創業者であるピーター・サビル氏とロジャー・ホールズワース氏が開発したパーソナリティ検査です。職場で「よくとる行動」や「好みの行動スタイル」を明らかにするよう設計されています。

公式に説明されている特徴は次のとおりです。

| 項目 | 公式の説明 |
|---|---|
| 測るもの | 「人との関係」「考え方」「感情・エネルギー」の3つの領域で、30のパーソナリティ因子 |
| 回答形式 | 「自分に最もあてはまるもの」と「最もあてはまらないもの」を選ぶイプサティブ（強制選択）形式 |
| 形式の狙い | 自分を良く見せようとする回答の傾向（社会的望ましさバイアス）を抑える |
| 対応言語 | 40以上の言語 |

## 問題の形

玉手箱Ⅲのページでは、性格検査を「4つの行動に関する記述の中から、自分に最も近いものを一つ、最も遠いものを一つ選び、職務上の行動特性を予測します」と説明しています。日本SHLの公式コラムでは、4つの記述は社会的な望ましさがそろうように並べられているとも書かれています。つまり、どれを選んでも「いかにも良い答え」になるようには作られていません。

本ノートで作った例を1つ示します。実際の問題ではありません。

> 次の4つのうち、自分に最も近いものと最も遠いものを1つずつ選んでください。
>
> - 初対面の人とも気軽に話せる
> - 計画を立ててから作業に取りかかる
> - 新しいやり方を試すのが好きだ
> - 周りの人の気持ちに気を配る

どれも長所に見える記述なので、「どれが評価されそうか」を考えても答えは決まりません。自分が実際に職場や学校でどう動くかで選ぶしかない作りです。

就活サイトでは、玉手箱の性格検査として、行動特性を問うもののほかに意欲などを問う検査が出ると紹介されることもあります。公式の玉手箱Ⅲのページに書かれているのはOPQだけです。

## 受けるときの心構え

日本SHLは公式コラムで、GABの性格検査について、全社に共通する正解の性格はなく、各社が求める人物像が違うこと、その後の面接などで結果との整合性が確かめられることから、「受検者側の対策という概念があまり当てはまりません」と書いています。玉手箱Ⅲの性格検査も同じOPQです。

そのうえで、受けるときに気をつけたいことは次の3つです。

- **職場や学校での自分を思い浮かべる。** SHLの受検者向けサイト[SHL Direct](https://www.shl.com/shldirect/jp/practice-tests/)は、性格の質問に答えるときは家庭や友人との関係ではなく、職場での行動について考えることが特に重要だとしています。
- **長く迷わない。** 4つとも当てはまる、どれも当てはまらないと感じる組み合わせもあります。それでも決めて進むしかないので、最初の直感を大切にしてください。
- **面接で話せる自分でいる。** 日本SHLは、玉手箱Ⅲの結果を「受検者に対する仮説」として面接で確かめる使い方を企業に勧めています。結果と面接での話が大きく食い違わないよう、普段の自分で答えるのがいちばん安全です。

## 時間について

日本SHLが公表しているのは玉手箱Ⅲ全体の所要時間（合計49分）と、言語・計数・英語の各約10分です。性格検査だけの問題数や時間は公表されていません。
