# 時間配分

玉手箱で点を落とす一番の原因は、問題の難しさよりも時間です。日本SHLは玉手箱Ⅲの言語・計数・英語をそれぞれ「約10分」、全体で「合計49分」としています。その短い時間に多くの問題が詰め込まれていると就活サイトでは報告されています。

## 1問あたりの時間

ワンキャリアがまとめた非公式の目安（[出典](sources.md#就活サイト非公式の目安)）から、1問あたりの時間を計算すると次のようになります。企業によって問題数や時間が違うことがあるので、本番では例題の画面で確認してください。

| 形式 | 非公式の目安 | 1問あたり | 1問にかけてよい時間の上限（本ノートの目安） |
|---|---|---|---|
| 四則逆算 | 50問／9分 | 約11秒 | 20秒 |
| 図表の読み取り | 29問／15分 | 約31秒 | 50秒 |
| 表の空欄の推測 | 20問／20分 | 60秒 | 90秒 |
| 論理的読解（GAB形式） | 32問／15分 | 約28秒 | 1文章で3分 |
| 趣旨判定（IMAGES形式） | 32問／10分 | 約19秒 | 1文章で2分 |
| 趣旨把握 | 10問／12分 | 72秒 | 2分 |
| 英語（各形式） | 24問／10分 | 25秒 | 1文章で2分 |

「上限」は本ノートの考え方で、ここまで来たら残りの選択肢から選んで次に進む、という目安です。

## 時間内に解き切るための工夫

- **画面の残り時間を区切りで確認する。** 四則逆算なら10問ごとに、図表なら1つの図表が終わるごとに残り時間を見ます。
- **電卓を使う問題と使わない問題を分ける。** 四則逆算の多くは暗算や概算のほうが速く、図表の割合計算は電卓のほうが確実です。電卓が使えるかどうかは受検方式や企業によります。
- **言語は設問を先に読む。** 本文を頭から精読する時間はありません。設問のキーワードを本文で探します。
- **迷ったら選んで進む。** 就活サイトの説明どおり誤答で減点されないなら、空欄で残すのがいちばんの損です（減点の有無は公式には公表されていません）。

## 時間が足りなくなる典型的なパターン

1. **最初の数問で慎重になりすぎる。** 例題の後、最初の5問で時間を使いすぎると取り返せません。
2. **1問の検算に時間をかける。** 検算は選択肢でざっと確かめる程度にします。
3. **言語で全文を読み直す。** 趣旨判定では、趣旨を一文にまとめておけば設問ごとに読み直す必要はありません。

## 時間を計って練習する

解き方を知っていても、時間の感覚は実際に計って解かないと身につきません。本ノートの練習問題も、慣れてきたら上の表の「1問あたり」の時間で解いてみてください。PrepClubsの[計数・論理のSHL形式の無料テスト30問（36分）](https://prepclubs.com/ja/tamatebako-taisaku?utm_source=github&utm_medium=referral&utm_campaign=study-notes&utm_content=tamatebako)も、時間を計った練習に使えます。玉手箱と同じ形式ではない点には注意してください。
