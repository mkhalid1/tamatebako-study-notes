# 受検当日のチェックリスト

自宅のパソコンで受けるWebテストを想定したチェックリストです。会場で受ける場合は、企業の案内に従ってください。

## 前日まで

- [ ] 受検期限の日時を確認した（締め切りの直前は避ける）
- [ ] 案内メールのテスト名と所要時間を確認した（[見分け方](format-check.md)）
- [ ] 推奨環境（OS、ブラウザ、通信環境）を案内で確認した
- [ ] 電卓やメモ用紙が使えるかを案内で確認した
- [ ] 使う電卓の操作（メモリー、％キー）に慣れておいた
- [ ] 夜はしっかり眠る

## 受検の1時間前

- [ ] パソコンを充電し、電源につないだ
- [ ] 通知やほかのアプリを切った
- [ ] 50分ほど邪魔の入らない時間と場所を確保した（玉手箱Ⅲの公式の所要時間は合計49分）
- [ ] 電卓、メモ用紙、筆記用具、時計を手元に置いた
- [ ] 四則逆算を数問だけ解いてウォーミングアップした

## 例題の画面で

- [ ] どの形式かを確認した（[画面の特徴と形式の対応](format-check.md#画面の特徴と形式の対応)）
- [ ] 問題数と制限時間が表示されていれば、1問あたりの時間を計算した
- [ ] 選択肢の意味（特に言語のA・B・C）を確認した

## 受検中

- [ ] 1問で止まりすぎず、上限を過ぎたら選んで次へ進む（[時間配分](timing.md)）
- [ ] 言語は設問を先に読む
- [ ] 図表は単位と分母を確認してから計算する
- [ ] 性格検査は職場や学校での普段の自分を思い浮かべて答える

## 受検の後

- [ ] 迷った形式や時間が足りなかった形式をメモしておく（次の選考で同じテストが出たときに役立つ）
- [ ] 受検が完了した画面や確認メールを保存しておく

## 最後の練習

受検前に一度、時間を計って通しで解いておくと、本番で焦りにくくなります。PrepClubsの[計数・論理のSHL形式の無料テスト30問（36分）](https://prepclubs.com/ja/tamatebako-taisaku?utm_source=github&utm_medium=referral&utm_campaign=study-notes&utm_content=tamatebako)が使えます。玉手箱と同じ形式ではありませんが、時間内に処理する練習になります。
