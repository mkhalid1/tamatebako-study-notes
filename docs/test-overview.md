# 玉手箱とはどんなテストか

玉手箱は、日本エス・エイチ・エル株式会社（以下、日本SHL）が提供する適性検査のシリーズ名です。就職活動で「玉手箱」と言う場合、たいていは自宅のパソコンで受けるWebテストの玉手箱Ⅲを指します。このページでは、日本SHLの公式ページに書かれていることと、就活サイトなどで報告されている非公式の情報を分けて整理します。

## 基本情報

日本SHLの[玉手箱Ⅲの公式ページ](https://www.shl.co.jp/service/assessment/tamatebako3/)に書かれている内容です（2026年11月25日確認）。

| 項目 | 公式ページの記載 |
|---|---|
| 提供元 | 日本エス・エイチ・エル株式会社 |
| 測定項目 | 言語・計数・英語・パーソナリティ（OPQ） |
| 所要時間 | 合計49分 |
| 科目ごとの時間 | 言語・計数・英語 各約10分 |
| ノルム（比較対象の集団） | 大卒 |
| 実施形態 | Web |
| 結果帳票 | 面接ガイド付き帳票と、タイプ分類のあるコメント形式帳票のどちらかを、企業が契約時に選ぶ |

公式ページに載っていないこと：問題数、合格ライン、誤答の扱い、電卓の使用可否、受検者への結果の開示。これらは本ノートでも「公表されていない」として扱います。

## 公式に書かれている科目

玉手箱Ⅲのページで、日本SHLは各科目を次のように説明しています。

| 科目 | 公式の科目名 | 公式の説明（要約） |
|---|---|---|
| 計数 | 計数理解テスト（四則逆算） | 簡単な四則演算を組み合わせた等式の未知数を求める、迅速で正確な推理能力を見る |
| 言語 | 言語理解テスト（大意把握） | 1000文字程度のエッセイを読み、筆者の訴えたい趣旨を正確に判断する |
| 英語 | 英語 | 200語から400語程度の文章を読み、設問が文章の論理に照らして正しいかを判断する |
| 性格 | パーソナリティ（OPQ） | 4つの行動の記述から、自分に最も近いものと最も遠いものを1つずつ選ぶ |

## 就活サイトで紹介されている出題形式

就活サイトや市販の対策本では、玉手箱の名前で受けるWebテストには、上の公式科目のほかにも次の形式が出ると広く紹介されています。科目ごとに1つの形式が選ばれ、その科目の最後まで同じ形式が続く、というのが就活サイトの説明です。これは日本SHLが公表している情報ではありません。

| 科目 | 形式（就活サイトでの呼び方） | 日本SHLの公式ページでの扱い | 問題数・時間の目安（非公式、ワンキャリア） |
|---|---|---|---|
| 計数 | [四則逆算](sections/shisoku-gyakuzan.md) | 玉手箱Ⅲの計数として記載あり | 50問／9分 |
| 計数 | [図表の読み取り](sections/zuhyo-yomitori.md) | GABの「計数理解テスト（図表理解）」として記載あり | 29問／15分 |
| 計数 | [表の空欄の推測](sections/kuuran-suisoku.md) | 該当する記載は見当たらない | 20問／20分 |
| 言語 | [論理的読解（GAB形式）](sections/ronriteki-dokkai.md) | GABの「言語理解テスト（論理）」として記載あり | 32問／15分 |
| 言語 | [趣旨判定（IMAGES形式）](sections/shushi-hantei.md) | 玉手箱Ⅲ・IMAGESの「言語理解テスト（大意把握）」の説明にいちばん近い | 32問／10分 |
| 言語 | [趣旨把握](sections/shushi-haaku.md) | 独立した記載は見当たらない | 10問／12分 |
| 英語 | [論理的読解・長文読解](sections/eigo.md) | 玉手箱Ⅲの英語として記載あり | 各24問／10分 |

問題数と時間はワンキャリアの記事にある目安で、ワンキャリア自身も企業によって異なる場合があると書いています（[出典](sources.md#就活サイト非公式の目安)）。公式の「各約10分」と合わない形式もあることに注意してください。

## なぜ企業によって中身が違うのか

日本SHLは、玉手箱Ⅲのような決まった組み合わせのテストのほかに、「SHLのもつ様々な適性テスト科目、尺度を組み合わせて」企業独自のテストを作る[オリジナルWebテスト](https://www.shl.co.jp/service/consulting/customized-test/)も提供しています。受検者から見て「同じ玉手箱なのに形式が違う」と感じる理由の一つは、ここにあると考えられます。ただし、どの企業がどの組み合わせを使っているかは公表されていません。

## 日本SHLのほかのテスト

同じ日本SHLのテストでも、時間や科目がかなり違います。公式ページの記載をまとめると次のとおりです。

| テスト | 測定項目（公式） | 所要時間（公式） | 実施形態（公式） |
|---|---|---|---|
| 玉手箱Ⅲ | 言語・計数・英語・パーソナリティ | 合計49分 | Web |
| 玉手箱Ⅰ | パーソナリティに関する質問紙、行動・経験に関するアンケート | 合計11分 | 記載なし |
| GAB | 言語・計数・英語・パーソナリティ | 80分から90分 | 紙、Web、テストセンター方式 |
| WebGAB Plus One | 言語・計数・オプション1科目・パーソナリティ | 89分から100分 | Web |
| IMAGES | 言語・計数・英語・パーソナリティ | 60分 | 紙 |

玉手箱Ⅰは能力検査のない、短いアンケート形式のテストです。案内のテスト名が「玉手箱Ⅰ」なら、計数や言語の対策は必要ありません。自分がどれを受けるのかの確かめ方は[出題形式の見分け方](format-check.md)にまとめました。

## このテストで大切な考え方

玉手箱は、1問ずつじっくり考えるテストではありません。日本SHLも、玉手箱Ⅲを「短時間で」能力を測るテストと説明しています。一つひとつの問題は難しくなくても、時間内にどれだけ正確に処理できるかで差がつきます。対策の中心は、形式ごとの解き方を決めておき、時間を計って練習することです。

## 時間を計った練習

本ノートの各形式のページで解き方をつかんだら、時間を計って解く練習をしましょう。PrepClubsの[玉手箱対策ページ](https://prepclubs.com/ja/tamatebako-taisaku?utm_source=github&utm_medium=referral&utm_campaign=xycwfk&utm_content=tamatebako)では、計数・論理のSHL形式の無料テスト30問（36分、日本語の解説付き）を受けられます。玉手箱と同じ形式ではありませんが、時間内に数字と論理を処理する練習になります。
