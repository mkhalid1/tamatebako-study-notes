# 用語集

本ノートに出てくる言葉を五十音順にまとめました。「公式」とあるものは日本SHLの公式ページで使われている言葉、「就活サイト」とあるものは就活サイトや対策本で使われている呼び方です。

| 用語 | 意味 |
|---|---|
| **IMAGES** | 日本SHLのマークシート式の適性検査（公式）。言語・計数・英語・パーソナリティを合計60分で測る。就活サイトの「IMAGES形式」は、この検査と同じ種類の問題という意味。 |
| **イプサティブ形式** | 複数の記述の中から「最もあてはまるもの」と「最もあてはまらないもの」を選ぶ回答形式（公式）。強制選択形式とも呼ばれる。OPQが採用している。 |
| **WebGAB Secure** | AIプロクタリング（監視機能）を搭載したWeb形式のGAB（公式）。 |
| **OPQ** | Occupational Personality Questionnairesの略。SHLのパーソナリティ検査で、30のパーソナリティ因子を測る（公式）。玉手箱Ⅲの性格検査として使われている。 |
| **オリジナルWebテスト** | SHLのテスト科目や尺度を組み合わせて、企業独自に作る適性テスト（公式）。 |
| **CAB（キャブ）** | ITエンジニアやデジタル人材のポテンシャルを測る日本SHLの適性検査（公式）。四則逆算、法則性、命令表、暗号の科目がある。 |
| **GAB（ギャブ）** | Graduate Aptitude test Batteryの略。日本SHLの総合適性検査で、言語理解テスト（論理）と計数理解テスト（図表理解）などからなる（公式）。就活サイトの「GAB形式」は、この検査と同じ種類の問題という意味。 |
| **四則逆算** | □が入った式の□を求める形式（公式の科目名は計数理解テスト（四則逆算））。 |
| **趣旨** | 筆者が文章でいちばん訴えたいこと。 |
| **趣旨判定** | 設問文が趣旨か、本文にあるが趣旨ではないか、本文と関係ないかを選ぶ形式（就活サイト）。公式の「言語理解テスト（大意把握）」の説明にいちばん近い。 |
| **趣旨把握** | 文章の趣旨をいちばんよく表す選択肢を選ぶ形式（就活サイト）。サイトによっては大意把握とも呼ぶ。 |
| **図表の読み取り** | 表やグラフから必要な数字を拾って計算する形式（就活サイト）。公式にはGABの計数理解テスト（図表理解）にあたる。 |
| **大意把握** | 公式には、玉手箱Ⅲ・IMAGESの言語科目の名前として使われている。1000文字程度のエッセイを読み、筆者の訴えたい趣旨を判断する。就活サイトでは趣旨把握の別名として使われることもあり、紛らわしい。 |
| **玉手箱Ⅰ** | パーソナリティの質問紙と、行動・経験のアンケートからなる日本SHLのテスト（公式）。合計11分で、能力検査はない。 |
| **玉手箱Ⅲ** | 言語・計数・英語・パーソナリティを合計49分で測る日本SHLのWebテスト（公式）。就活で「玉手箱」と言うと、ふつうこれを指す。 |
| **テストセンター方式** | 全国の会場に出向き、本人確認を受けてから受検する方式（公式、GABなど）。 |
| **ノルム** | 得点を比べる基準となる集団。玉手箱Ⅲのノルムは大卒（公式）。 |
| **表の空欄の推測** | 表の「？」の欄に入る値を、ほかの行の規則から推測する形式（就活サイト）。公式ページには該当する説明が見当たらない。 |
| **標準点** | 集団の中での位置を一定の段階で表す得点。GABの得点は10段階の標準点で算出される（公式）。 |
| **例題** | 本題の前に解く練習問題。日本SHLの適性検査には、すべて本題の前に例題がある（公式）。 |
| **論理的読解** | 設問文が本文の論理から正しいか、間違っているか、判断できないかを選ぶ形式（就活サイト）。公式にはGABの言語理解テスト（論理）にあたる。 |
