# 採点と結果

先に結論を書くと、玉手箱の採点方法の細かい部分や合格ラインは、日本SHLから公表されていません。公表されているのは、結果が大卒の集団と比べて出されることと、企業が受け取る帳票の種類です。このページでは、公式に分かっていること、公表されていないこと、就活サイトで言われていることを分けて整理します。

## 公式に分かっていること

日本SHLの[玉手箱Ⅲの公式ページ](https://www.shl.co.jp/service/assessment/tamatebako3/)に書かれている内容です。

- **ノルムは「大卒」。** ノルムとは、得点を比べる基準になる集団のことです。玉手箱Ⅲの結果は、大卒の集団と比べてどの位置にいるかで示されると考えられます。
- **結果帳票は2種類。** ①行動特性と、面接での質問例や判別指標のついた面接ガイド付き帳票、②タイプ分類とコメント形式の帳票のどちらかを、企業が契約時に選びます。
- **企業での使われ方。** 初期のふるい分けのほか、面接での確認、内定者へのフィードバック、配属の参考などに使えると説明されています。

参考までに、同じ日本SHLのGABについては、公式コラムで「GABの得点は標準点と呼ばれる10段階の得点ですべて算出されます」と説明されています。玉手箱Ⅲの得点の表し方は公式ページに書かれていないため、同じだとは言い切れません。

## 公表されていないこと

| 項目 | 状況 |
|---|---|
| 合格ライン（ボーダー） | 公表されていない。各企業が独自に決めていると考えられる |
| 誤答の扱い（減点の有無） | 公式ページに記載がない |
| 受検者への結果の開示 | 玉手箱Ⅲのページに記載がない |
| 問題数 | 公表されていない |

なお、性格の質問紙だけで構成される玉手箱Ⅰについては、オプションで結果を受検者にオンラインでフィードバックできると公式ページに書かれています。玉手箱Ⅲにはこの記載がありません。

## 就活サイトで言われていること

以下は日本SHLの公表情報ではなく、就活サイトの説明です。

- **誤答で減点されない。** ワンキャリアは、玉手箱は誤答率を評価しておらず、正しく答えた数を数えていると説明しています（[出典](sources.md#就活サイト非公式の目安)）。これが正しければ、分からない問題を空欄のまま残すより、何かを選んだほうが有利です。
- **「7割」「8割」という目安。** 検索するとよく見かける数字ですが、日本SHLは合格ラインを公表していません。こうした数字は就活サイトの推測で、根拠は示されていないことがほとんどです。

## どう考えればよいか

合格ラインが分からない以上、受検者にできることは次の2つです。

1. **1問でも多く、正確に答える。** 減点の有無は公式には不明ですが、時間切れで答えられなかった問題が得点にならないことは確かです。時間の使い方は[時間配分](timing.md)を見てください。
2. **苦手な形式をなくす。** 科目ごとに1つの形式が出るという報告どおりなら、苦手な形式が出た科目はまるごと失点しやすくなります。[診断テスト](diagnostic.md)で弱い形式を見つけ、先に対策しましょう。

練習では、時間を計ったうえで各形式8割以上の正答を一つの目安にしてください。これは本ノートの学習上の目安であり、合格ラインではありません。
