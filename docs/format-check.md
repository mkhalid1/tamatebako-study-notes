# 出題形式の見分け方

玉手箱は、科目ごとにどの形式が出るかが企業によって違うと言われています。対策の時間が限られているときほど、「自分が受けるのはどのテストか」「どの形式が出たか」を早く見分けることが大切です。ここでは、受検の前と受検中の2つの段階に分けて確かめ方をまとめます。

## 受検の前に確かめること

### 案内メールのテスト名

まず、企業から届く受検案内にテスト名が書かれていないかを確認します。日本SHLのテストには玉手箱Ⅲのほか、GAB、CAB、IMAGES、玉手箱Ⅰなどがあり、それぞれ科目も時間も違います（[テストの一覧](test-overview.md#日本shlのほかのテスト)）。

### 案内に書かれた所要時間

テスト名が書かれていなくても、所要時間が手がかりになることがあります。日本SHLの公式ページの記載は次のとおりです。

| 案内の所要時間 | 考えられるテスト（公式ページの所要時間） |
|---|---|
| 50分前後 | 玉手箱Ⅲ（合計49分） |
| 10分強 | 玉手箱Ⅰ（合計11分、能力検査なし） |
| 80分以上 | GAB（80分から90分）、WebGAB Plus One（89分から100分） |

ただし、企業独自に科目を組み合わせた[オリジナルWebテスト](https://www.shl.co.jp/service/consulting/customized-test/)もあるため、時間だけで決めつけないでください。案内に書かれた時間が、上の表のどれとも合わないこともあります。

### 受検方式

自宅で受けるのか、テストセンターなどの会場で受けるのかも確認しておきます。日本SHLは、GABについて自宅で受けるWeb形式、会場で受けるテストセンター形式（C-GAB plus）、マークシート形式の3つがあると説明しています。また、AIによる監視機能を備えた[WebGAB Secure](https://www.shl.co.jp/service/assessment/gab/webgabsecure/)というWeb形式もあります。会場で受ける場合や監視付きの場合は、電卓やメモの扱いが自宅受検と違うことがあるので、案内をよく読みましょう。

## 受検中に見分ける

### 例題の画面を使う

日本SHLは公式コラムで、同社の適性検査は「すべて本題の前に例題が用意され、受検者は必ず練習問題を経て受検します」と書いています。例題の画面で形式が分かるので、ここで次の表と照らし合わせ、本ノートのどの解き方を使うかを決めてください。例題の画面には問題数や制限時間も表示されることが多いと就活サイトでは紹介されています（非公式）。

### 画面の特徴と形式の対応

| 画面に出てくるもの | 形式 | 解き方のページ |
|---|---|---|
| 「□」が入った式と、数値の選択肢 | 四則逆算 | [四則逆算](sections/shisoku-gyakuzan.md) |
| 表やグラフと、割合や金額を問う設問 | 図表の読み取り | [図表の読み取り](sections/zuhyo-yomitori.md) |
| 1つの欄が「？」になっている表 | 表の空欄の推測 | [表の空欄の推測](sections/kuuran-suisoku.md) |
| 文章と設問文、選択肢が「正しい・間違っている・判断できない」 | 論理的読解（GAB形式） | [論理的読解](sections/ronriteki-dokkai.md) |
| 文章と設問文、選択肢が「趣旨である・趣旨ではない・関係ない」 | 趣旨判定（IMAGES形式） | [趣旨判定](sections/shushi-hantei.md) |
| 文章と、趣旨の候補の中から1つを選ぶ設問 | 趣旨把握 | [趣旨把握](sections/shushi-haaku.md) |
| 英文と設問 | 英語 | [英語](sections/eigo.md) |
| 4つの行動の記述から「最も近い」「最も遠い」を選ぶ | 性格検査（OPQ） | [性格検査](personality.md) |

### 言語の3形式の見分け方

言語の3形式は、どれも文章を読む点が同じなので取り違えやすくなります。見るべきは**選択肢**です。

- 選択肢が「正しい・間違っている・判断できない」の3つなら論理的読解
- 選択肢が「趣旨である・趣旨ではない・関係ない」の3つなら趣旨判定
- 文章1つにつき、趣旨の候補から1つを選ぶ形なら趣旨把握

論理的読解と趣旨判定は、同じ文章でも答えが変わります。例えば本文に書かれている具体例は、論理的読解では「正しい」ですが、趣旨判定では「趣旨ではない」です。

## 見分けた後にすること

形式が分かったら、その形式の1問あたりの時間を思い出してください。非公式の目安から計算すると、四則逆算は約11秒、図表の読み取りは約31秒、表の空欄の推測は約60秒です。詳しくは[時間配分](timing.md)のページにまとめています。
