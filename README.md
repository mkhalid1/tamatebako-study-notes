# 玉手箱 対策ノート

日本エス・エイチ・エル（日本SHL）のWebテスト「玉手箱」を受ける人のための、無料の対策ノートです。テストの仕組み、計数・言語・英語の形式ごとの解き方、オリジナルの練習問題30問（すべて解説付き）、性格検査の考え方、採点についての公式情報、1週間と2日間の学習プランをまとめました。テストについての事実は、日本SHLの公式ページだけをもとにし、すべて[出典](docs/sources.md)を示しています。日本SHLが公表していない問題数や時間は、就活サイトの非公式の目安であることを明記しています。

まず実力を確かめたい方は、このノートの[15分診断テスト](docs/diagnostic.md)から始めてください。時間を計って解く練習には、PrepClubsの[玉手箱対策ページ](https://prepclubs.com/ja/tamatebako-taisaku?utm_source=github&utm_medium=referral&utm_campaign=study-notes&utm_content=tamatebako)にある計数・論理のSHL形式の無料テスト30問（36分、日本語の解説付き）も使えます。玉手箱そのものの形式ではありませんが、時間内に数字と論理を処理する練習になります。

## はじめに

1. **苦手な形式を見つける。** [15分診断テスト](docs/diagnostic.md)を受けてください。5つの形式から7問を出題し、どこから始めればよいかが分かります。
2. **いちばん苦手な形式から直す。** 下の表からその形式のページを開き、解き方の手順を読んでから練習問題を解きます。
3. **プランに沿って進める。** 1週間あるなら[7日間プラン](docs/study-plans.md#7日間プラン)、受検期限が近いなら[2日間プラン](docs/study-plans.md#2日間プラン)を使ってください。

## 形式の一覧

| 科目 | 形式 | 何をするか | 公式ページでの扱い | ページ |
|---|---|---|---|---|
| 計数 | 四則逆算 | □が入った式の□を求める | 玉手箱Ⅲの科目として記載 | [四則逆算](docs/sections/shisoku-gyakuzan.md) |
| 計数 | 図表の読み取り | 表やグラフから割合や金額を計算する | GABの図表理解として記載 | [図表の読み取り](docs/sections/zuhyo-yomitori.md) |
| 計数 | 表の空欄の推測 | 表の「？」に入る値を規則から推測する | 記載なし | [表の空欄の推測](docs/sections/kuuran-suisoku.md) |
| 言語 | 論理的読解（GAB形式） | 設問文が本文から正しいか、間違いか、判断できないかを選ぶ | GABの言語（論理）として記載 | [論理的読解](docs/sections/ronriteki-dokkai.md) |
| 言語 | 趣旨判定（IMAGES形式） | 設問文が筆者の趣旨かどうかを選ぶ | 玉手箱Ⅲの大意把握の説明に近い | [趣旨判定](docs/sections/shushi-hantei.md) |
| 言語 | 趣旨把握 | 文章の趣旨を表す選択肢を1つ選ぶ | 記載なし | [趣旨把握](docs/sections/shushi-haaku.md) |
| 英語 | 論理的読解・長文読解 | 英文を読み、設問が正しいかを判断する | 玉手箱Ⅲの科目として記載 | [英語](docs/sections/eigo.md) |
| 性格 | OPQ | 4つの記述から最も近いものと遠いものを選ぶ | 玉手箱Ⅲの科目として記載 | [性格検査](docs/personality.md) |

計数と言語の各ページは、次の順に書いています。何を測っているか、問題の形、解き方の手順、よくあるミス、時間の目安、オリジナルの練習問題と解説、自己採点。

## このノートの使い方

- **GitHub上でそのまま読めます。** どのページにも「前へ」「次へ」「目次に戻る」のリンクがあるので、本のように最初から順に読み進められます。
- **答えを見る前に決める。** 答えは「答えと解説」を開くと表示されます。自分の答えを決めてから開いてください。
- **正解した問題の解説も読む。** 多くの解説には、近い選択肢がなぜ違うのかを書いています。そこがいちばんの学びになります。
- **間違いを記録する。** 間違えた問題ごとに、どこで間違えたかを1行で書いておきましょう。やり方は[学習プラン](docs/study-plans.md#間違えた問題の振り返り方)にあります。
- **時間を計って練習する。** このノートは解き方を教えるものです。ペースは時間を計った練習で身につきます。
- **クローンやフォークも自由です。** 自分用に書き込みたい方はどうぞ。GitBookの形式でも読めます（[SUMMARY.md](SUMMARY.md)）。

## 練習問題について

練習問題30問（各形式のページに23問、診断テストに7問）は、すべてこのノートのために作ったオリジナル問題です。玉手箱の実際の問題、日本SHLの資料、ほかの対策サイトや対策本の問題は使っていません。就活サイトで紹介されている各形式の作りに合わせてあるので、ここで身につけた解き方は本番でもそのまま使えます。

| ページ | 問題数 |
|---|---|
| 四則逆算 | 4 |
| 図表の読み取り | 4 |
| 表の空欄の推測 | 3 |
| 論理的読解（GAB形式） | 4 |
| 趣旨判定（IMAGES形式） | 4 |
| 趣旨把握 | 2 |
| 英語 | 2 |
| 15分診断テスト | 7 |
| **合計** | **30** |
